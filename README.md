# 大富翁之金聪明游浙江（开发预览版）

按《浙江之旅》V3 设计方案实现的多人在线大富翁（游戏名：大富翁之金聪明游浙江）。当前为本地预览版，可在同一台电脑开多个标签页对局，用来检查规则、界面和流程。

## 怎么试玩（本地多标签页）

用本地服务器打开，避免浏览器 file:// 下多标签页数据不互通。进入 zhejiang-trip 目录后运行：

    python -m http.server 8000

然后浏览器打开 http://localhost:8000 ，输入昵称点「创建房间」；再开一个标签页打开同一网址，输入另一个昵称和房间号点「加入房间」；房主设置好参数后点「开始游戏」。

掉线重连：关掉某个标签页再重新打开，首页会提示「重新连接」，点一下即可回到对局。

## 已实现的核心规则

- 62 格环形地图：浙江 11 地级市 + 严州，含 2 个起点、乔司监狱、卡牌补给站、命运×2、机会×2、空地、12 个特色地块。
- 两个起点随机分配，经过自己起点 +¥3000（逆向也生效）。
- 大地块 1/2/3 区域，首次到达最多买 2 个（顺序购买、补差价），买满后需下次到达才能建建筑。
- 建筑 5 级顺序升级，每次最多升 2 级（补差价）。
- 四档地产价格、基础过路费、同城普通地产加成、特色地块独立收集加成。
- 6 种卡牌：逆向 / 霸王 / 停留 / 作弊 / 爆破 / 拆除，只能在掷骰子前使用；霸王卡使用后 3 回合内免一次过路费，用过即消。
- 乔司监狱：进入立即掷骰，单数离开、双数停留 1 回合。
- 命运 ×10（无选择立即执行：暂停/损失/获得/后移 3 格）与机会 ×10（把握/放弃，把握后掷机会骰子，偶数成功奇数失败）。
- 特色地块可像普通地块一样选择购买或跳过；购买价 = 最贵一档（第一档）的空地价格 ¥1200，收入基础 = 最贵一档的无建筑地租 ¥300，实际收入再乘「特色地块拥有数量」加成。
- 抵押：整个大地块一起抵押，按 50% 返还，地块回归银行；资金不足可紧急抵押，仍不足则破产。
- 回合状态机：行动阶段 → 掷骰 → 锁定 → 移动 → 结算 → 下一回合。

## 需要你确认的几处（设计文档未明确，我先按合理方式处理）

1. 破产后地产归属：文档未说明，我暂定回归银行（无主），如需转给债主请说明。
2. 命运/机会的损失：命运损失扣到 0 为止；机会「把握」需要当前资金 ≥ 该卡的「损失」额，以免变成负数。
3. 特色地块暂不可抵押（没有区域/建筑，无抵押价值）。

## 联机说明（重要）

当前是本地多标签页联机（同一浏览器内用 BroadcastChannel + localStorage 同步），还不能跨真实设备联网。要实现中国玩家不挂梯子、跨设备实时联机，需要接入腾讯云开发 CloudBase：你提供「环境 ID」后，我把房间存储和实时同步接到云上，届时不同设备即可通过房间号联机。代码结构已为接入云做预留。
